# Evidencias de sistema — Aplicación

La aplicación AgeCare Marketing está formada por cuatro proyectos que viven en la raíz de este repositorio (no se duplican aquí para no tener dos copias que se desincronicen):

| Carpeta | Qué es |
|---|---|
| [`backend/`](../../../../backend/) | API de la Consola de Administración (FastAPI + PostgreSQL) |
| [`frontend/`](../../../../frontend/) | Consola de Administración (React + Vite + TypeScript) |
| [`backend-general/`](../../../../backend-general/) | API del sitio público |
| [`webapp/`](../../../../webapp/) | Sitio público (React + Vite + TypeScript) |
